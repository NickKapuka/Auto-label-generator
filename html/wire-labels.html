Wire Label Generator

Upload a wire CSV to automatically sort the wire marks, create duplicate labels for both wire ends, and generate a .pemx file ready for printing.

Input Files

Upload the exported wire report from SWE as CSV

Wire Processing

The wire number should appear in the first column of the CSV. Other columns will be ignored during processing.

Each wire number will be automatically duplicated to create a label for both ends of a wire.

Empty rows and the header row will be ignored and removed during processing.
