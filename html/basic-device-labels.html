Basic Processing

Device marks and descriptions will be directly taken from the uploaded CSV.

Marks will be bolded and descriptions placed under them using the standard labels formatting

This includes 10pt font for the marks and either 7-9pt font for the descriptions to fit the length.

Marks without descriptions will remain in the review table where they can be accepted or excluded before generating the final file.

This tool will not create, correct, or recommend device descriptions.
