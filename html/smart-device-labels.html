Device Labels

Smart Device Label Generator

Process device marks, descriptions, and part numbers to identify any missing or inconsistent descriptions before generating the final .pemx project.

Input Files

Upload the component report exported from SWE as a CSV.

Select the PEMX template included with this application

Smart Processing

Device marks, existing descriptions and manufacturer part numbers (third column) will all be examined during processing.

A part-number lookup table will be used to recommend any missing descriptions or format existing ones into the standardized format.

Recommendations will be loaded into a table where they may be accepted, rejected, or edited before the final PEMX file.

The original CSV will not be modified.
