Automating Labels

Create Wire, Cable, and Device Labels Automatically

By Nick Kapuka

Converts exported SWE data (SWE -> Excel -> CSV) into a fully formatted Easy-Mark Plus project. No manual sorting and styling by hand.

Choose what type of generator you would like to use. Each will redirect you to a new page with a guided walkthrough on its use.

View Label Tools

How it works:

  1. Choose the tool from the list below
  2. Export the required report from SWE as an Excel
  3. Convert it into an CSV and upload it here
  4. Upload the PEMX template included in this project
  5. Review the generated labels
  6. Generate the PEMX pre-render
  7. Download the final .pemx file

File requiremenets:

Excel files (.xlsx) are not supported. Export the SWE report as a CSV in Excel and upload it here. Don't remove columns or any sorting. The selected tool expects the default SWE export and handles the cleanup and formatting.

The PEMX template must still be selected manually because this application runs in a browser. A PEMX template has been provided inside this project as "template.pemx" for easy access.

Select the type of labels you want to generate. Each tool requires different input files and processes data differently.

Wire Labels

Reads wire numbers from a CSV import, sorts them, duplicates each label for both ends of the wire, and generates a .pemx file ready for printing.

Requires:Wire export as CSV

Go to wire label generator

Wire and Cable Labels

Processes two wire and cable CSVs together and generates both sets in the same .pemx with proper formatting.

Requires:Wire CSV and cable CSV

Go to wire and cable label generator

Basic Device Labels

Formats the marks and descriptions existing in the CSV without generating automatic recommendations or any heavy post-processing. Use this if you put descriptions on most components in SWE.

Requires: Component CSV

Go to basic device label generator

Smart Device Labels

Adds description recommendations using a part-number lookup table. These can be accepted, reject, or edited before the final export occurs.

Useful if descriptions are left blank or formatted incorrectly.

Requires: Component CSV
